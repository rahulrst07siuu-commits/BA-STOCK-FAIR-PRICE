STOCK PRICE PREDICTION APP

Files:
1. app.py - Streamlit application
2. model_bundle.joblib - Saved trained models and preprocessing

To run the app:

pip install -r requirements.txt

streamlit run app.py

Dataset:
stock_price_prediction_sample_synthetic.csv

Note:
The supplied dataset is synthetic and intended for educational use.
Predictions should not be treated as actual market prices or investment advice.
